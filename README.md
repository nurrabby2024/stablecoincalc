## About

Converts between fiat and stablecoin amounts with live rate input.

## Features

- Fast, dependency-free core
- Clean command line interface with sensible defaults
- Configurable via flags or a JSON config file
- Careful error handling with typed failures
- Unit tested core with CI ready to wire up

## Install

```bash
git clone https://github.com/nurrabby2024/stablecoincalc.git
cd stablecoincalc
```

## Usage

```bash
stablecoincalc --help

stablecoincalc run -o ./out -v
```
